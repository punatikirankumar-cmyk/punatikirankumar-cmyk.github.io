# Kiran Kumar Punati — GitHub Pages Portfolio

This is a static GitHub Pages portfolio for `kiran-kumar-punati.github.io`.

## Publish
1. Create a GitHub repository named `kiran-kumar-punati.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Visit `https://kiran-kumar-punati.github.io`.

The resume is included at `assets/Kiran_Punati_Resume.pdf`.
